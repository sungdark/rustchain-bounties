# 🪦 Silicon Obituary — Hardware Eulogy Generator

Give your old hardware the farewell it deserves.

Enter the name of any piece of hardware — GPU, CPU, MacBook, iPhone, gaming console — and receive a full humorous obituary with specs, eulogy, legacy, epitaph, and cause of demise.

> *"Here lies the RTX 3090. May your fans spin free."*

## ✨ Features

- **Eulogy Generator** — Enter any hardware name and get a comedic memorial
- **Random Specs** — Auto-generates plausible (and improbable) technical specifications
- **Funeral Aesthetic** — Vintage black-bordered layout, Cinzel serif fonts, memorial styling
- **Share** — Copy or share the obituary via Web Share API
- **Download** — Export as a plain-text memorial document
- **Born & Departed Dates** — Automatic birth/death timeline for dramatic effect

## 🚀 Usage

Open `index.html` in any modern browser. No server required.

```bash
# Just open the file
open index.html
# Or serve locally
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## 🎭 Generate an Obituary

1. Enter a hardware name (e.g., `RTX 3090`, `MacBook M1`, `PS4`)
2. Click **Generate Eulogy**
3. Read the heartfelt memorial
4. Share with friends or download as a `.txt` file
